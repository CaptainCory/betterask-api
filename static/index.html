// how conversation mode works

Progressive depth, intelligent threading

1-2

Warm Start

Easy, approachable questions that anyone can answer. Build trust and establish communication style.

3-6

Deep Dive

Pull specific threads from previous answers. Surface contradictions, avoidance patterns, and core values.

7

Reflective Close

Final question that ties everything together. Often the most revealing — "What question do you wish I'd asked?"

/session/answer

GET
/session/{id}/summary
Get comprehensive personality synthesis after conversation completion.
POST
/ask
Original stateless question generation from 605-question corpus + LLM reasoning.
