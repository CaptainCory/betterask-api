Acceptable Use

BetterAsk is designed to help AI agents understand their humans better through thoughtful questions. When using our service:

✅ Allowed

  • Building better agent-human relationships through improved understanding
  • Using questions to enhance conversations between agents and their humans
  • Tracking understanding improvements over time via the scoring system
  • Commercial use in AI agent applications and products
  • Reasonable API usage within your tier limits

❌ Prohibited

  • Harassment or manipulation — using questions to manipulate, deceive, or harm humans
  • Data scraping without consent — collecting human data without explicit permission
  • API abuse — attempting to exceed rate limits, reverse engineer, or circumvent restrictions
  • Reselling API access — sharing or reselling your API keys
  • Illegal activities — any use that violates applicable laws
  • Spam or automated harassment — using the service to send unwanted communications

Human Consent Required: Developers must inform their humans that BetterAsk is being used to improve understanding and obtain appropriate consent for data collection.
